## 01 · The actual story

I'm a Principal Program Manager in Revenue Operations who got tired of waiting for engineering bandwidth — so I started building the tools myself.

My work sits at the intersection of **AI, automation, and business operations**. I write the PRD and then ship the tool. Claude Code and n8n are how I close the gap between strategy and execution.

```
What I do            →   Revenue ops strategy, AI GTM, automation
How I do it          →   Python pipelines, AI agents, React frontends
What makes it rare   →   Most PMs don't ship. I do.
```

## 04 · Minor projects

- **🔭 Buildathon Radar** — a personal AI agent that scans Devpost, Devfolio, and Luma every week, filters for events worth an AI PM's time, and emails a ranked digest every Sunday. `Python` · `Claude` · [repo](https://github.com/Jcube101/buildathon-radar)
- **🧿 Alchmyth Charm Studio** — full-stack storefront for handmade charms and stationery: catalog, cart, server-priced Razorpay checkout, and a custom-quote workflow. Built at the Razorpay × Replit Hackathon. `TanStack Start` · `PostgreSQL` · `Razorpay` · [repo](https://github.com/Jcube101/alchmyth-charm-studio)
- **🪐 Mars Colony Manager** <sub>· WIP</sub> — turn-based browser systems game. One meaningful decision a month, a two-month lag on consequences, and a living ecosystem that rewards foresight over reaction. `TypeScript` · `Vite` · [repo](https://github.com/Jcube101/mars-colony-manager) · [live](https://mars.job-joseph.com)
- **🐦 Echo** <sub>· WIP</sub> — turns any audio clip into an interactive 3D trail through pitch/timbre/motion space, with synced playback and a spectrogram strip. `React` · `Three.js` · `librosa` · [repo](https://github.com/Jcube101/echo) · [live](https://echo.job-joseph.com)
- **🎬 Hugin** — movie mood recommender: describe how you're feeling, get the right film. Claude interprets the mood, TMDb + OMDb find the picks. `Python` · `FastAPI` · `Claude` · [repo](https://github.com/Jcube101/hugin) · [live](https://job-joseph.com/projects/hugin)
- **🚗 Commute Lens** — ingests GPS tracks, enriches them with weather and fuel data, and surfaces patterns in a daily city commute: departure windows that beat traffic, routes that underperform, hidden stops. `Python` · `Open-Meteo` · `OSRM` · [repo](https://github.com/Jcube101/commute-lens)
- **📡 Signal Digest** — a personal AI agent that monitors RSS sources, filters through a defined lens, and delivers a weekly digest. A script executes steps; an agent makes decisions. `Python` · `Claude` · `feedparser` · [repo](https://github.com/Jcube101/signal-digest)
- **🔥 Daily Forge** <sub>· Paused</sub> — minimal habit app for building a consistent daily posting habit. Write, copy, paste, mark done. `Python` · `FastAPI` · `SQLite` · [repo](https://github.com/Jcube101/daily-forge)
- **🏏 Cricket Notifier** — a Go service that watches live India cricket matches and pings Telegram only when something matters: wickets, milestones, results. `Go` · `Telegram` · `systemd` · [repo](https://github.com/Jcube101/cricket-notifier)
- **📌 Notice Board** — a digital corkboard for notes, checklists, and hot takes, free-positioned on a canvas and persisted to self-hosted PocketBase. `React` · `PocketBase` · `shadcn/ui` · [repo](https://github.com/Jcube101/notice-board) · [live](https://job-joseph.com/notice-board)
- **🔐 Password Manager** — local-first CLI password manager storing everything in a single encrypted file. Argon2id + AES-256-GCM, 28 passing tests. `Python` · `cryptography` · [repo](https://github.com/Jcube101/password-manager)
- **🌏 Sentinel** — real-time natural disaster tracker for India: fire, quakes, floods, cyclones, air quality from five public APIs on a live map. `Python` · `Supabase` · `React` · [repo](https://github.com/Jcube101/sentinel) · [live](https://sentinel-frontend-8hem.onrender.com)
- **📖 Pocket Stories** — browser-only interactive fiction editor and player. Author branching YAML stories in a visual node-graph editor, no backend. `React` · `TypeScript` · `Vite` · [repo](https://github.com/Jcube101/pocket-stories) · [live](https://Jcube101.github.io/pocket-stories/)
- **🌐 Word Translator** — FastAPI microservice that translates `.docx` documents via Sarvam AI, built for Indic language pairs. `Python` · `FastAPI` · `Sarvam AI` · [repo](https://github.com/Jcube101/word-translator)
