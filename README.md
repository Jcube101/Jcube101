## 01 · The actual story

I'm a Principal Program Manager in Revenue Operations who got tired of waiting for engineering bandwidth — so I started building the tools myself.

My work sits at the intersection of **AI, automation, and business operations**. I write the PRD and then ship the tool. Claude Code and n8n are how I close the gap between strategy and execution.

```
What I do            →   Revenue ops strategy, AI GTM, automation
How I do it          →   Python pipelines, AI agents, React frontends
What makes it rare   →   Most PMs don't ship. I do.
```

## 04 · Minor projects

- **🐦 Echo** <sub>· WIP</sub> — turns any audio clip into an interactive 3D trail through pitch/timbre/motion space, with synced playback and a spectrogram strip. `React` · `Three.js` · `librosa` · [live](https://echo.job-joseph.com)
- **🎬 Hugin** — movie mood recommender: describe how you're feeling, get the right film. Claude interprets the mood, TMDb + OMDb find the picks. `Python` · `FastAPI` · `Claude` · [live](https://job-joseph.com/projects/hugin)
- **🚗 Commute Lens** — ingests OsmAnd GPS tracks, enriches with weather and fuel data, and surfaces patterns in a daily Bengaluru commute. `Python` · `Open-Meteo` · `OSRM`
- **📡 Signal Digest** — a personal AI agent that monitors RSS sources, filters through a defined lens, and delivers a weekly digest. A script executes steps; an agent makes decisions. `Python` · `Claude` · `feedparser`
- **🔥 Daily Forge** <sub>· WIP</sub> — minimal habit app for building a consistent daily posting habit. Write, copy, paste, mark done. `Python` · `FastAPI` · `SQLite`
- **🏏 Cricket Notifier** — a Go service that watches live India cricket matches and pings Telegram only when something matters: wickets, milestones, results. `Go` · `Telegram` · `systemd`
- **📌 Notice Board** — a digital corkboard for notes, checklists, and hot takes, free-positioned on a canvas and persisted to self-hosted PocketBase. `React` · `PocketBase` · `shadcn/ui` · [live](https://job-joseph.com/notice-board)
- **🔐 Password Manager** — local-first CLI password manager storing everything in a single encrypted file. Argon2id + AES-256-GCM, 28 passing tests. `Python` · `cryptography`
- **🌏 Sentinel** — real-time natural disaster tracker for India: fire, quakes, floods, cyclones, air quality from five public APIs on a live map. `Python` · `Supabase` · `React` · [live](https://sentinel-frontend-8hem.onrender.com)
- **📖 Pocket Stories** — browser-only interactive fiction editor and player. Author branching YAML stories in a visual node-graph editor, no backend. `React` · `TypeScript` · `Vite` · [live](https://Jcube101.github.io/pocket-stories/)
- **🌐 Word Translator** — FastAPI microservice that translates `.docx` documents via Sarvam AI, built for Indic language pairs. `Python` · `FastAPI` · `Sarvam AI`
